# IRC-108 RAG AI Assistant

A Retrieval-Augmented Generation (RAG) based AI Assistant developed for IRC:108.

## Features
- PDF ingestion and chunking
- Vector embeddings using OpenAI Embeddings
- ChromaDB vector database
- Retrieval-based question answering
- Built using LangChain and OpenAI

## Project Structure
- ingestion_pipeline.py
- retrieval_pipeline.py
- QA_bot.py
- irc.gov.in.108.1996.pdf

## Future Work
This project serves as a preliminary step towards developing a more advanced Road Safety Audit AI Assistant incorporating multiple IRC codes, Agentic RAG, and Multimodal RAG capabilities.
